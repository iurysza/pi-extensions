What changed

Before: each package attached card code to its own tools with ownedCard(...). After: tidy registers one resolver. If a spec matches the tool name (exact, or mcp__<server>__<tool>), it returns the card. Otherwise, or when tidy is off, it returns next() unchanged.

resolver(name, next):
  if !tidy.enabled      -> next()
  spec = specForTool(name)
  if spec               -> cardRenderers(spec, cardRuntime)   // expanded falls back to next() renderers
  else                  -> next()

Chill mode (/chill, per session, default off via chill in ~/.pi/agent/pi-tidy-tools.json): finished calls between text turns fold into Worked · N tools · duration plus a red failure count. Working shows while a call runs. Ctrl+O shows everything. Stored messages and results never change.
